셀프 출원을 고민하던 고객이 착수금 부담 없이 웹에서 5분 안에 출원을 신청하고, 사무소는 직원의 수작업 없이 대리인으로 자동 지정되어 등록 단계 수익으로 이어지는 구조를 만듭니다. 가장 우려하신 "위임장 생성과 특허청 자동 입력·첨부의 안정성"은 착수 3주 안에 실제 시범 검증으로 먼저 확인하고 개발을 진행합니다.

핵심 요구사항 분석

  • 회원가입 및 출원 신청 폼: 출원인 필수 개인정보·상표 정보를 단계별(스텝 폼)로 쉽게 입력, 임시 저장·이어 쓰기
  • 대리인 자동 지정 및 위임장 PDF 생성: 변리사님이 사전 세팅된 대리인 정보 + 고객 정보 + 도장·서명 이미지를 표준 위임장 양식에 자동 합성
  • 상표 이미지 규격 처리 및 AI 보조: 업로드 이미지를 특허청 상표견본 규격에 맞게 검사·변환, AI로 상품류·지정상품 선택 지원
  • 특허청 자동 입력·첨부·제출: 출원인·상표·대리인 정보 자동 기입, 위임장 PDF·상표 JPG 자동 첨부, 공동인증서 인증 후 제출, 접수번호·출원 상태 연동
  • 결제: 관납료·서비스 이용료 자동 산출, 신용카드·무통장입금(가상계좌) PG 연동
  • 사후 등록 안내: 마이페이지 진행 현황, 등록 결정 시 대리인 등록 절차·등록 수수료 결제 안내·진행
  • 통합 관리자 백오피스: 신청 내역·위임장·상표 이미지 확인, 자동 입력·제출 상태 모니터링 및 재처리, 회원·결제·심사/등록 단계 관리, 알림 발송
  • 인프라: 클라우드 서버·DB 구축, 특허청 연동 구동 환경(Windows 자동화 PC) 세팅, 상용 배포

제안 포인트

① 위임장 PDF 자동 생성 — 기술적 구현 방안

고객 정보 입력→ 도장 업로드 / 서명 그리기→ 도장 배경 제거·보정→ 표준 양식 합성→ 미리보기·위임 동의→ PDF 확정·보관
  • 양식 템플릿화: 사무소의 대리인 위임장 표준 양식을 HTML 템플릿(또는 원본 PDF 위 좌표 지정)으로 그대로 재현하고, 대리인(변리사님) 성명·대리인번호·주소는 관리자에서 한 번만 세팅합니다. 양식이 바뀌면 관리자에서 새 버전으로 교체하며, 이미 생성된 위임장은 당시 버전 그대로 보존됩니다.
  • 도장 이미지 처리: 휴대폰으로 찍은 도장 사진도 배경(흰 종이·그림자)을 자동 제거하고 인주 색만 추출해 투명 PNG로 만든 뒤, 양식의 "(인)" 위치에 정확한 크기로 합성합니다. 도장이 없는 고객은 화면에서 직접 서명을 그리는 방식도 제공합니다.
  • PDF 생성: 서버의 헤드리스 브라우저(Puppeteer)로 한글 폰트를 내장한 PDF를 생성하고, 원본 PDF 양식 채우기가 필요한 경우 pdf-lib로 처리합니다. 고객은 생성된 위임장을 화면에서 미리 보고 "위임에 동의합니다"에 체크한 뒤 확정합니다.
  • 증빙 기록: 위임 동의 시각·IP·기기 정보와 PDF 파일 해시를 함께 저장해, 추후 분쟁 시 고객이 직접 위임했다는 근거를 남깁니다.
  • 특허청 제출 규격: 생성 PDF를 특허청 첨부서류 규격(파일 형식·용량·해상도)에 맞춰 자동 검사하고, 규격을 벗어나면 제출 전에 관리자에게 표시합니다.

② 특허청 자동 입력·첨부·제출 — 기술적 구현 방안

특허청은 상표출원을 외부 서비스가 직접 접수할 수 있는 공개 API를 제공하지 않기 때문에, 사람이 하던 화면 입력·첨부를 프로그램이 대신 수행하는 자동화(RPA) 방식이 현실적인 방법입니다. 이때 핵심은 "빠르게"보다 "틀리지 않고, 실패해도 바로 알 수 있게" 만드는 것입니다.

웹 접수·결제 완료→ 관리자 출원 대기열→ 자동화 에이전트 서식 기입·첨부→ 변리사 최종 확인 1클릭→ 공동인증서 서명·제출→ 접수번호 회수·고객 알림톡
구분A. 특허청 웹출원(특허로) 화면 자동화B. 특허청 전자출원 PC 소프트웨어 제어
방식브라우저 자동화(Playwright)로 웹 서식 화면에 입력·첨부Windows UI 자동화(pywinauto)로 서식작성·제출 프로그램 조작
장점입력 항목을 화면 요소 단위로 정확히 찾아 기입, 단계별 화면 캡처가 쉬워 모니터링에 유리사무소 직원분들이 익숙한 기존 업무 방식과 동일, 대량 처리에 강함
유의점특허로 화면 개편 시 입력 위치 보정 필요프로그램 업데이트·팝업 변화에 민감, 화면 해상도 고정 필요
권장Day 7~21 두 방식을 실제 상표 1건 기준으로 시범 검증(PoC)한 뒤, 성공률·처리 시간·유지보수성을 비교 보고드리고 하나를 주 방식, 다른 하나를 예비 방식으로 확정합니다. 현재 기준으로는 화면 요소를 정확히 식별할 수 있는 A안(웹출원 자동화)을 주 방식으로 권장합니다.
  • 구동 환경 — 사무소 내 전용 자동화 PC: 특허청 제출은 대리인(변리사님) 공동인증서로 서명하므로, 인증서를 클라우드에 올리지 않고 사무소 내 전용 Windows PC(또는 전용 Windows 가상 서버)에서만 사용합니다. 이 PC의 에이전트가 클라우드 서버에서 "출원 작업"을 가져가는 방식(바깥으로만 연결)이라 사무소 PC에 외부 접속 포트를 열 필요가 없습니다.
  • 변리사 최종 확인 후 제출: 자동 기입·첨부가 끝나면 관리자 화면에 "입력 결과 캡처 + 위임장 + 상표 견본"이 나란히 표시되고, 변리사님이 확인 후 [제출 승인]을 누르면 서명·제출이 진행됩니다. 하루 단위 일괄 승인도 지원합니다. 자동화의 편리함은 유지하면서 대리인 책임 하의 제출 구조를 지킵니다.
  • 실패 대응: 단계마다 화면을 캡처·기록하고, 입력값과 화면 결과가 다르면 즉시 중단 → 관리자에 "재처리 필요"로 표시 → 원인 확인 후 [재시도] 버튼으로 해당 단계부터 다시 실행합니다. 같은 건이 두 번 제출되지 않도록 출원 건별 잠금 처리를 합니다.
  • 접수번호·상태 연동: 제출 완료 화면·수신 문서에서 출원번호를 자동 회수해 고객 마이페이지와 알림톡으로 안내하고, 이후 심사 진행 상태는 KIPRIS Plus(특허청 공공데이터 API) 조회와 관리자 수동 갱신을 병행합니다.
  • 특허고객번호: 특허고객번호가 없는 신규 출원인은 부여 신청이 먼저 필요하므로, 이 신청도 같은 자동화 흐름에 포함할지 미팅에서 확정합니다.

③ 반응형 웹 vs 모바일 앱 — 권장 방향: 반응형 웹(PWA) 우선 오픈

판단 기준반응형 웹 우선모바일 앱 병행
고객 이용 패턴상표출원은 1인당 1~2회 이용하는 서비스 → 설치 없이 바로 쓰는 웹이 이탈이 적음설치 단계에서 이탈, 출원 후 재방문 빈도 낮음
고객 유입"상표출원 셀프", "상표등록 비용" 검색 유입이 핵심 → 검색엔진 노출(SEO)에 유리한 웹이 필수앱은 검색 노출이 되지 않아 별도 마케팅 필요
입력 편의PC에서 도장 스캔본·로고 파일 업로드가 편하고, 모바일 웹에서도 카메라 촬영 업로드 지원장점 적음
진행 알림카카오 알림톡으로 접수·출원번호·심사 결과 안내 → 앱 푸시 없이도 충분푸시 알림 가능
비용·기간예산을 디자인 품질과 특허청 연동 안정성에 집중스토어 심사·앱 개발로 약 800만~1,200만원·3~4주 추가

결론: 1차는 PC·모바일 반응형 웹 + PWA(홈 화면 추가)로 오픈해 예산을 디자인 퀄리티와 자동화 안정성에 집중하고, 오픈 후 재방문·등록 단계 이용 데이터를 보고 필요하면 같은 웹을 그대로 감싸는 하이브리드 앱(WebView)을 2차로 3~4주 안에 출시하는 방식을 권장합니다. 1차부터 앱 전환을 고려한 구조로 만들어 추가 비용을 최소화합니다.

④ 일반 대중을 위한 고감도 UI/UX

  • 스텝 폼 설계: "상표 정보 → 상품류 선택(AI 추천) → 출원인 정보 → 도장·서명 → 위임장 확인 → 결제" 6단계, 진행률 표시와 단계별 쉬운 설명·예시로 처음 출원하는 고객도 막힘없이 완료
  • 신뢰를 주는 디자인: 법률 서비스 특유의 딱딱함 대신 깔끔하고 친근한 톤, 비용 계산기·진행 단계 타임라인 시각화, 변리사 대리 출원임을 명확히 표시
  • 디자인 검증: 무드보드 2안 → 메인·스텝 폼 시안 확정 후 전체 확장, Figma 클릭형 프로토타입으로 실제처럼 눌러 보며 피드백

⑤ AI 활용 출원 보조 — 제안 범위

  • 상품류·지정상품 추천: 고객이 "온라인으로 수제 쿠키를 판매합니다"처럼 사업 내용을 적으면, AI가 니스 상품류와 특허청 고시 지정상품 명칭 중에서 후보를 추천합니다. 고시 명칭 데이터 안에서만 고르도록 해 엉뚱한 명칭이 나오지 않게 합니다.
  • 유사 상표 사전 확인(참고용): KIPRIS Plus 검색 결과를 바탕으로 비슷한 기존 상표를 보여 주고, 변리사 상담 유도로 연결합니다(법적 판단이 아닌 참고 정보로 표시).

지금은 상표출원 의뢰가 오면 직원이 워드·한글로 위임장을 작성해 PDF로 변환하고, 특허청 소프트웨어에 정보와 상표 JPG를 일일이 입력합니다. 또한 비용 부담으로 유튜브·블로그를 보며 셀프 출원을 시도하는 고객이 많습니다. 본 플랫폼은 이 고객들을 착수금 없이 웹으로 끌어들이고, 사무소가 대리인으로 자동 지정되어 등록 단계에서 수익화하는 구조를 만듭니다.

  • 목표 1: 일반 고객이 웹에서 쉽고 빠르게 상표출원을 신청·결제 (PC·모바일 반응형)
  • 목표 2: 위임장 작성·특허청 입력·첨부 수작업 제거, 변리사 확인 1클릭 제출
  • 목표 3: 출원 → 심사 → 등록 결정 → 등록 대행·등록 수수료 결제로 이어지는 수익 흐름
  • 제약: 3~4개월 내 정식 오픈, 예산 4,000만~5,000만원 턴키
